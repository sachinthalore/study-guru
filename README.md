# 🎓 Study Guru

Study Guru is an AI-powered study assistant that helps students learn faster using Google's Gemini AI.

It allows students to:

- 🤖 Chat with AI
- 📚 Ask questions from uploaded notes
- 📖 Subject-specific AI assistance
- 📝 Manage study notes
- ⚡ Fast and secure backend architecture

---

# 🚀 Features

- AI Chat using Gemini API
- Global Chat
- Notes-based Chat
- Subject-specific Chat
- Professional Express Backend
- API Versioning
- Global Error Handling
- Request Validation (Zod)
- Winston Logging
- Morgan Logging
- Compression
- Helmet Security
- Rate Limiting
- Health Check API

# ⚙️ Installation

Clone repository

```bash
git clone https://github.com/sachinthalore/study-guru.git
```

Install dependencies

```bash
npm install
```

Create

```
.env
```

Add

```env
API_KEY=YOUR_GEMINI_API_KEY
PORT=3000
```

Run project

```bash
npm start
```
