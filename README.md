# Study Guru 📚🤖

Study Guru is an AI-powered study assistant that helps students learn faster using Google Gemini AI.

## Features

- 💬 AI Chat
- 📄 Notes Upload (.txt & .pdf)
- 📝 Short Notes Generation
- 🔑 Keyword Extraction
- 🧠 Test Generator

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Google Gemini API

## Installation

```bash
git clone https://github.com/sachinthalore/study-guru.git
cd study-guru
npm install
```

## Environment Variables

Create a `.env` file:

```env
API_KEY=YOUR_GEMINI_API_KEY
PORT=3000
```

## Run

```bash
node server.js
```
